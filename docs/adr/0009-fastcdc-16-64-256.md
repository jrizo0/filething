# FastCDC adaptativo: 16/64/256 KiB para código, 256 KiB/1 MiB/4 MiB para binarios

filething sincroniza código, no backups, así que partimos los archivos con FastCDC en normalized chunking nivel 2 y parámetros `min`=16 KiB / `avg`=64 KiB / `max`=256 KiB (ratio 1:4:16), no el ~256K/1M/4M típico de un backup tipo restic. La gear table se siembra con el chunk secret aleatorio por-Space (no derivado de la Space key, ver ADR 0010), de modo que rotar la Space key no re-chunkea el mundo y los cortes son impredecibles entre Spaces.

Enmienda 2026-07-24, motivada por un `init` real de 441 MB de PDFs que produjo
3,946 Blocks y otros tantos sidecars: el perfil anterior sigue siendo el default,
pero archivos binarios conocidos de al menos 1 MiB usan 256 KiB / 1 MiB / 4 MiB.
La selección depende solo de tamaño y extensión ASCII case-insensitive, por lo que
dos Devices toman la misma decisión sin agregar estado al Manifest. Incluye
imágenes, audio/video, archives, formatos Office/PDF, bases SQLite/Parquet y
otros contenedores binarios enumerados en `ft-engine::scan`.

Los Blocks no codifican un máximo normativo en su header: clientes anteriores
pueden descargar y materializar Blocks de hasta 4 MiB porque el Manifest ya lleva
la lista y el decoder valida la longitud declarada, no el perfil que creó el
Block. Un cliente anterior que vuelva a escanear el mismo binario puede
re-chunkearlo con el perfil pequeño y producir una Revision distinta; no pierde
datos, aunque conviene actualizar todos los Devices para evitar ese churn.

## Considered Options

- **avg ~1 MiB global (rechazado):** con ese avg, todo archivo de fuente < 256 KiB sería 1 solo Block; editar 1 byte re-subiría el archivo entero y mataría el delta intra-archivo. Se conserva 16/64/256 para código y se aplica 1 MiB solo a binarios grandes.

## Consequences

- El dedup NO cruza Spaces: el mismo archivo en dos Spaces produce cortes y `cid` distintos. Aceptado y coherente con scope de dedup = Account/Space, no global.
- Mitiga el fingerprinting de tamaños de objeto (canal lateral), al ser los cortes secretos por-Space.
